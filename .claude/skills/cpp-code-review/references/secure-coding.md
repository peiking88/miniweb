## 安全编码原则

### 不信任外部输入
应用程序必须验证所有用户输入，然后再根据用户输入执行操作。对任何非受控的系统外部输入，都不要假定其安全性。

### 最小化
尽可能少让用户输入信息，返回错误消息时不要公开不需要的信息，任何返回的错误详细信息有助于攻击者发现漏洞。

### 失败终止
对用户提交的数据进行安全性检查时，如果发现数据不符合要求应终止业务执行。

### 纵深防御
多层安全机制叠加，不依赖单一防线。

## 输入验证

### 常见用户输入处安全漏洞
- SQL注入
- 反序列化注入
- 注入恶意代码
- 参数超出范围导致内存溢出
- 恶意order by导致数据库慢查询
- 任意重定向

### 检查要求
- [ ] 所有外部输入是否经过验证和过滤
- [ ] 输入长度、类型、范围是否限制
- [ ] 是否存在未验证的用户输入直接拼接到命令/查询中
- [ ] 是否对特殊字符（`< > & " ' /`）进行转义

## SQL注入防护

### 安全编码要求
- 使用参数化查询（PreparedStatement），禁止拼接SQL
- 使用ORM框架时确保不引入HQL/JPQL注入
- 限制数据库账户权限（最小权限原则）
- 对排序字段（order by）白名单校验

### 禁止
```cpp
// 禁止：直接拼接用户输入到SQL
std::string sql = "SELECT * FROM users WHERE id = " + userId;
```

### 推荐
```cpp
// 推荐：参数化查询
// C++中使用预处理语句
sqlite3_stmt *stmt;
sqlite3_prepare_v2(db, "SELECT * FROM users WHERE id = ?", -1, &stmt, nullptr);
sqlite3_bind_text(stmt, 1, userId.c_str(), -1, SQLITE_TRANSIENT);
```

## XSS防护

### 安全编码要求
- 对输出到HTML的变量进行编码转义
- 过滤字符：单引号、双引号、大于号、小于号、&符号
- 在变量输出时进行HTML编码处理
- 设置Content Security Policy (CSP)

### 检查要求
- [ ] 用户输入是否在输出前做HTML转义
- [ ] 是否设置了CSP头
- [ ] 是否存在反射型/存储型XSS风险

---

## CSRF防护

### 安全编码要求
- 验证HTTP Referer
- 设置严格的CSP
- 表单中填充一次性随机CSRF Token
- 关键操作加入二次验证（密码/验证码/OTP）

### 检查要求
- [ ] 关键操作是否有CSRF Token校验
- [ ] Token是否为一次性且随机
- [ ] 是否验证Referer来源

## 文件上传安全

### 安全编码要求
- 白名单验证文件扩展名
- 验证文件MIME类型
- 重命名上传文件（随机文件名）
- 上传目录不可执行
- 限制文件大小
- 存储到Web根目录外

### 检查要求
- [ ] 是否白名单校验文件类型
- [ ] 是否检查MIME类型
- [ ] 上传路径是否可遍历
- [ ] 文件名是否重命名

## 路径遍历防护

### 安全编码要求
- 验证和规范化文件路径
- 检查路径是否在允许的目录内
- 禁止用户输入直接拼接文件路径

### 禁止
```cpp
// 禁止：用户输入直接拼路径
std::string path = "/data/files/" + userInput;
std::ifstream file(path);
```

### 推荐
```cpp
// 推荐：路径规范化+白名单校验
namespace fs = std::filesystem;
fs::path baseDir = "/data/files/";
fs::path filePath = baseDir / userInput;
fs::path canonical = fs::canonical(filePath);
if (canonical.string().find(baseDir.string()) != 0) {
    // 路径遍历攻击
    return false;
}
```

## 身份认证安全

### 图形验证码要求
- 添加干扰线，动态生成，不重复
- 一次性使用，验证后立即更新
- 验证码内容保存在服务端

### 短信验证码要求
- 验证手机号一致性
- 验证码是否已使用
- 验证码是否超时
- 限制发送频率

### 密码安全
- 使用安全哈希算法（bcrypt/scrypt/Argon2）
- 禁止明文存储密码
- 密码复杂度要求

## 会话安全

### Cookie安全
- 设置HttpOnly属性
- 设置Secure属性（仅HTTPS传输）
- 合理设置Expires
- 使用随机Session ID

### Session安全
- Session ID必须随机且不可预测
- 登录时重建Session（防会话定置攻击）
- 设置合理超时时间
- 验证User-Agent和Token

### 检查要求
- [ ] Cookie是否设置HttpOnly和Secure
- [ ] Session ID是否随机
- [ ] 登录是否重建Session
- [ ] 是否设置超时

---

## 密码与加密安全

### 安全编码要求
- 使用标准加密算法（AES-256、RSA-2048+）
- 禁止使用弱算法（MD5、SHA1用于安全场景、DES、RC4）
- 密钥管理安全，不在代码中硬编码密钥
- 使用安全随机数生成器

### 检查要求
- [ ] 是否硬编码密钥/密码/Token
- [ ] 加密算法是否安全
- [ ] 密钥管理是否规范
- [ ] 是否使用安全随机数

## 日志安全

### 安全编码要求
- 不记录未经验证的用户输入
- 不记录敏感信息（密码、个人隐私、身份信息）
- 记录：事件时间、来源IP、操作账号、事件内容、操作结果

### 禁止
```cpp
// 禁止：记录密码
LOG("User login: user=%s, password=%s", username, password);
```

### 推荐
```cpp
// 推荐：不记录敏感信息
LOG("User login: user=%s, result=%s", username, success ? "success" : "failed");
```

### 检查要求
- [ ] 日志是否包含密码等敏感信息
- [ ] 日志是否记录用户输入未经验证
- [ ] 是否有完整的审计日志

## 统一错误与异常处理

### 安全编码要求
- 用户登录失败模糊提示（"用户名或密码错误"）
- 错误信息不泄露系统信息、会话标识、源码、堆栈、内部IP
- 前端统一返回错误页面
- 异常不暴露技术细节

### 检查要求
- [ ] 错误信息是否模糊化
- [ ] 是否泄露系统/技术信息
- [ ] 异常处理是否统一

## 随机数安全

### 安全编码要求
- 安全场景使用密码学安全随机数生成器
- 禁止使用`rand()`/`srand()`生成安全Token
- C++使用`std::random_device`

### 禁止
```cpp
// 禁止：不安全随机数用于安全场景
srand(time(nullptr));
int token = rand();
```

### 推荐
```cpp
// 推荐：安全随机数
#include <random>
std::random_device rd;
std::uniform_int_distribution<int> dist(0, 999999);
int token = dist(rd);
```

## 防数据重放与篡改

### 防重放
- 重要操作添加随机数或时间戳保证唯一性
- 登录、注册、改密、交易等关键操作必须有防重放机制

### 防篡改
- 重要数据增加签名机制
- 添加时间戳或随机数
- 服务端校验数据完整性

## C/CPP高风险函数

### 线程不安全函数（全局/静态缓冲区）

内部使用静态变量存储状态，多线程环境下会互相踩踏。

| 函数 | 风险 | 安全替代 |
|------|------|---------|
| `strtok` | 内部静态缓冲区，多线程覆盖状态 | `strtok_r` |
| `strerror` | 返回静态缓冲区指针，多线程覆盖错误信息 | `strerror_r` |
| `gmtime` | 返回静态 `struct tm*`，并发结果错乱 | `gmtime_r` |
| `localtime` | 返回静态 `struct tm*`，并发结果错乱 | `localtime_r` |
| `ctime` | 返回静态字符串，线程不安全 | `ctime_r` |
| `asctime` | 返回静态字符串，线程不安全 | `asctime_r` |
| `tmpnam` / `tempnam` | 静态缓冲区，多线程文件名冲突 | `mkstemp` |
| `gethostbyname` | DNS相关，静态缓冲区，已废弃 | `getaddrinfo` / `freeaddrinfo` |
| `gethostbyaddr` | DNS相关，静态缓冲区，已废弃 | `getaddrinfo` / `freeaddrinfo` |
| `getenv` / `setenv` | 全局环境变量，多线程修改不安全 | 线程局部配置/配置结构体 |
| `system` / `popen` | 命令注入、阻塞、信号干扰 | `fork`+`exec` / 异步进程管理 |
| `abort` / `exit` | 直接终止进程，无清理，高可用服务禁用 | 异常处理/优雅退出 |

### 缓冲区溢出函数（字符串与内存）

#### 字符串操作

| 函数 | 风险 | 安全替代 |
|------|------|---------|
| `strcpy` | 无长度校验，缓冲区溢出 | `strncpy` / `std::string::assign` |
| `strcat` | 未检查目标缓冲区大小 | `strncat` / `std::string` 拼接 |
| `sprintf` | 格式化串溢出，无长度限制 | `snprintf` / `std::format` (C++20) |
| `gets` | 无长度限制，绝对禁止 | `fgets` |
| `scanf` | 无长度限制，缓冲区溢出 | `fgets` + 手动解析 |
| `strcmp` | 无长度保护 | `strncmp` |
| `wcscpy` | 宽字符串溢出 | `wcsncpy` |
| `wcslen` | 宽字符串长度无保护 | `wcsnlen` |

#### 内存操作

| 函数 | 风险 | 安全替代 |
|------|------|---------|
| `memcpy` | 内存重叠行为未定义 | `memmove`（支持重叠） |
| `memset` | 多线程非原子操作；清零敏感数据可能被优化器消除 | `explicit_bzero` / `memset_s` |

### IO与文件系统风险函数

| 函数 | 风险 | 安全替代 |
|------|------|---------|
| `fopen` | 无权限控制，不支持原子打开 | `fopen_s` / `open`（O_EXCL） / C++ `fstream` |
| `tmpnam` / `tempnam` | 文件名可预测，竞态条件 | `mkstemp` / `tmpfile` |
| `printf` / `fprintf` | 多线程输出乱序，非原子写入 | 加锁打印 / 异步日志库 / C++23 `print` |

### 破坏性函数（修改入参）

会在原字符串写 `\0`，传入 `const` 或只读内存直接段错误。

| 函数 | 风险 | 处理建议 |
|------|------|---------|
| `strsep` | 修改原串，不可重入 | 知道风险、能接受修改原串的场景 |
| `basename` / `dirname` | 可能修改原路径字符串 | 自己封装或传入可写副本 |

### 隐藏全局状态函数

内部维护全局状态，非线程安全，并发下行为未定义。

| 函数 | 风险 | 安全替代 |
|------|------|---------|
| `rand` / `srand` | 全局随机种子，多线程不可预测 | `rand_r` / C++11 `<random>` |
| `errno` | 多线程下被覆盖 | 立即读取、线程局部存储 |
| `setjmp` / `longjmp` | 跨函数跳转，破坏栈与状态 | C++异常（谨慎使用）或重构 |

### 隐式内存分配函数

内部隐式分配内存，调用者忘记释放导致泄漏。

| 函数 | 风险 | 处理建议 |
|------|------|---------|
| `strdup` | 隐式 `malloc`，经常忘记 `free` | 自己封装，强制配对 |
| `realpath` | 部分实现隐式分配内存，需释放 | 指定缓冲区版本 |

### 信号不安全函数

信号上下文中调用以下函数会导致死锁或崩溃。

**禁止在信号处理函数中调用：**
- 所有 `malloc`/`free`
- 所有标准IO函数
- 所有字符串不安全函数
- 所有非异步安全函数

**信号安全函数（允许使用）：**
- `write`、`sigqueue`、`sleep`、`_exit`、`signal`

### 后端开发禁止/慎用清单

| 分类 | 禁止函数 | 替换方案 |
|------|---------|---------|
| 多线程环境 | `strtok`、`strerror`、`gmtime`、`localtime`、`ctime`、`rand`、`gethostbyname` | 对应 `_r` 后缀版本 / `getaddrinfo` |
| 只读字符串入参 | `strtok`、`strsep`、`basename`、`dirname` | 传入可写副本 |
| 隐式分配 | `strdup`、`realpath` | 强制配对 `free` / 使用缓冲区版本 |
| 命令执行 | `system`、`popen` | `fork`+`exec` |

### 其他需注意函数

- `sscanf`、`fscanf`、`vfscanf`、`vsprintf`、`vscanf`、`vsscanf` — 格式化输入输出溢出
- `strlen()`、`realpath()`、`syslog()` — 需检查参数有效性
- `getopt()`、`getopt_long()`、`getpass()` — 需安全使用
- `bcopy()` — 已过时，使用 `memcpy`/`memmove`
